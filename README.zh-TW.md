# ⚡ Windows ContextTools (極速版右鍵工具箱)

基於 C# 原生編譯的 Windows 右鍵快捷工具箱，專為解決傳統 Python 腳本（需載入龐大的環境依賴如 `win32com`, `PyPDF2` 等）在右鍵選單所造成的 1 至 2 秒啟動延遲而設計。

[Read English Version](README.md)

## 📌 描述

在「右鍵 ➔ 執行」這種講求即點即反應的快速操作場景中，Python 每次重新初始化直譯器與資源庫的慢熱特性嚴重影響了使用體驗。
**ContextTools** 作為一個 C# 原生後端核心，確保每次的右鍵操作啟動延遲都極小化於 **0.05 秒之內**，點擊瞬間即刻發動引擎。

## ✨ 核心功能

- **⚡ 極速 PPTX 轉 PDF**：無縫呼叫本機端 PowerPoint 核心元件，在背景靜默幫您瞬間轉出排版 100% 精準的 PDF。
- **⚡ PDF 高速合併**：支援將選取的多份 PDF 檔案高效率合併為一份。
- **⚡ 圖片組合至 PDF**：選取多張圖片 (`.jpg`, `.png`)，一鍵封裝成單一共多頁的 PDF。
- **⚡ 圖片無縫拼貼**：選取多張圖片，程式將自動把所有圖片由上至下重直拼接成一條長圖片。
- **🛡️ 智慧檔名排序保護**：Windows 系統在處理多檔案全選時，經常會因為您最後一擊點擊的是哪個檔案而打亂傳入順序。本工具內建強制依據檔名 (A-Z) 排列的防呆機制，確保合併出來的順序永遠正確。

## 🚀 安裝與使用方式

1. **取得免安裝執行檔**：請確認資料夾內存在編譯好的 `ContextTools.exe`（如果沒有，請參閱下方自行編譯）。
2. **一鍵部署腳本**：對著 `setup_context_menu.ps1` 點擊右鍵 ➔ **【用 PowerShell 執行】**。程式將自動為您完成：
   - 針對單一 `.pptx` 檔的轉換，將直接完美嵌入您的 Windows 原生右鍵選單中。
   - 針對多選檔案的「合併功能」，為了避開 Windows 原生右鍵會失控狂開幾十個視窗的缺陷，我們為您設計在原生的 **「傳送到 (SendTo)」** 選單內，這也是 Windows 唯一完美支援多檔傳遞的最佳原生管道。

### 實際操作情境
- **只轉單份 PPTX**：對該檔案點擊右鍵 ➔ `⚡ 轉為 PDF (極速)`。
- **多檔案合併（圖片/PDF）**：全選要合併的檔案 ➔ 點擊右鍵 ➔ **傳送到 (Send to)** ➔ 選擇您要的 `⚡` 合併功能。

## 🛠️ 開發者指南（自行由原始碼編譯）

如果您在別的電腦拿到這份原始碼，想自行在當地重新鍛造出原生的執行檔：

**環境要求：**
- .NET SDK (推薦版本 8.0 以上)

依據您的需求，我們提供兩種編譯打包策略：

### 方案 1：極速閃電版（依賴本機框架）
*【極度推薦】體積僅約 150 KB，啟動時間 < 0.01 秒。* 直接借用系統現有的 .NET 引擎，適合在自己的電腦上使用。（前提是使用此程式的電腦需已安裝 .NET 桌面環境）
```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

### 方案 2：高規相容版（隨身碟便攜版）
*【高度便攜】體積約 75 MB，啟動時間約 0.08 秒。* 將整個微軟 `.NET 核心引擎` 封裝打包進單獨一顆 `.exe` 中，即使是完全乾淨、沒裝過任何環境的 Windows 電腦也能拷貝過去完美裸機運作。
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```
