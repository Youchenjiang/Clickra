## 說明 (Description)
【系統需求】「文書轉PDF」功能需於本機裝置安裝對應之 Microsoft Word 或 PowerPoint。

Clickra 是一款專為 Windows 10 與 Windows 11 打造的極速原生右鍵選單工具集。它能無縫整合至檔案總管選單，無須開啟任何龐大臃腫的軟體，就能瞬間完成檔案處理。

核心功能：
　　原生儀表板：全新深色模式介面，即時監測 Office 組件安裝狀態。
　　文書轉 PDF：支援 Word (.doc/.docx) 與 PPT (.ppt/.pptx) 靜默轉檔，高品質不跑版。
　　極速 PDF 合併：選取多個 PDF，右鍵一鍵合併。
　　圖片轉 PDF：快速將多張圖片封裝為 PDF。
　　圖片拼接：輕鬆將多張圖片垂直無縫結合。

Clickra 100% 於本機執行，保證隱私安全。立刻體驗閃電般的檔案處理速度！

🔗 開源專案首頁：https://github.com/Youchenjiang/Clickra

## 此版本的新增功能 (What's new in this version)
- 新增關於分頁 (About Tab)：包含專案說明、開源協作連結與一鍵 Gmail 診斷回報功能。
- 完整多語系支援：儀表板與右鍵選單新增日文 (ja-JP)、韓文 (ko-KR)、簡體中文 (zh-CN) 完整本地化。
- 最小化至系統匣：儀表板可最小化至 Windows 系統匣，雙擊圖示即可恢復視窗。
- 自訂輸出目錄：設定頁面新增原生資料夾選取器，可任意設定預設輸出路徑。
- 展開式歷史紀錄：轉換歷史項目可點擊展開，顯示輸入/輸出路徑與精確轉換耗時。
- 最大化佈局與高 DPI 模糊修正：修正最大化後黑區問題，並支援高 DPI 解析度螢幕下畫面清晰與字體縮放。
- 「檔案優先」智慧轉檔交互：支援使用者先拖入/選取檔案，自動偵測檔案類型並動態啟用對應轉檔選項。
