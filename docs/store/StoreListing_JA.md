## Product Name
Clickra

## Description
Clickra は、Windows のエクスプローラー向けに設計されたネイティブな右クリック拡張ツールです。ファイルを右クリックするだけで、Office 文書の PDF 変換、PDF の圧縮・分割・結合・パスワード解除、画像の形式変換や結合、Markdown 変換を素早く実行できます。

主要なファイル処理はすべてローカル環境でオフライン実行されるため、プライバシーが安全に保護されます（論文翻訳機能のみオンライン通信を使用します）。無料・オープンソース、NativeAOT による高速起動で、バックグラウンド常駐サービスもありません。

ソースコード：https://github.com/Youchenjiang/Clickra

## What's new in this version
- 保護対応の PDF パスワード解除：パスワード保護または印刷・コピー制限付きの PDF を自動認識。カード入力パスワードを優先試行し、制限のみの PDF はパスワード不要で即座に制限解除。
- 視覚的 PDF 分割ワークスペースの強化：ページの実際の縦横比に応じたサムネイル表示、ダブルクリックによる全画面拡大プレビュー（拡大縮小・ショートカット・アイコン対応）、全モードでの柔軟な分割ポイント調整をサポート。
- 最新デスクトップ UI プレビュー (Clickra.Desktop)：Avalonia による新世代クロスプラットフォーム デスクトップ アプリ。ドラッグ＆ドロップ、アクション カタログ、画像結合順序調整ワークスペースを提供（--desktop で起動可能）。
- 専用ワークスペースと操作性の向上：一括名前変更のリアルタイム プレビュー、Markdown テンプレート カード選択、ウィンドウ位置・サイズの記憶、ウィンドウ終了時のバックグラウンド継続処理に対応。
