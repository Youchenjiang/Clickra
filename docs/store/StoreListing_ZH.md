## Product Name
Clickra

## Description
Clickra 是一款 Windows 檔案總管的右鍵轉檔與 PDF 工具。

直接在檔案上點擊右鍵即可處理：
• 文書轉 PDF：Word、Excel、PPT
• PDF 工具：壓縮、解密、分割、合併
• 圖片工具：格式互轉、拼接長圖、轉 PDF
• Markdown：轉換為 PDF 或 Word
• 論文翻譯：保留排版與公式的 PDF 翻譯

所有檔案均 100% 於本機電腦離線處理，檔案不外傳。
免費、開源、無廣告，無背景常駐。

原始碼：https://github.com/Youchenjiang/Clickra
