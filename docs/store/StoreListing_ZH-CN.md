## Product Name
Clickra

## Description
Clickra 是一款 Windows 资源管理器的右键转档与 PDF 工具。

直接在文件上点击右键即可处理：
• 文档转 PDF：Word、Excel、PPT
• PDF 工具：压缩、解密、分割、合并
• 图片工具：格式互转、拼接长图、转 PDF
• Markdown：转换为 PDF 或 Word
• 论文翻译：保留排版与公式的 PDF 翻译

所有文件均 100% 在本机电脑离线处理，文件绝不外传。
免费、开源、无广告，无后台常驻。

源代码：https://github.com/Youchenjiang/Clickra

- 完整繁中、简中、英、日、韩五国语言
- 界面动态文本设置与密钥隐藏
