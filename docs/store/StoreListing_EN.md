## Product Name
Clickra

## Description
Clickra is a native Windows File Explorer context menu extension for fast document conversion and PDF processing. Right-click any file to convert Office documents to PDF, compress, split, merge, or decrypt PDFs, convert and stitch images, and format Markdown.

Core document operations run completely offline on your local PC to keep your data private, with an optional online PDF paper translation feature that preserves original layouts and formulas. Free, open source, natively compiled, and free of persistent background services.

Source Code: https://github.com/Youchenjiang/Clickra
