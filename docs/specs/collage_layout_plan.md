# 拼貼：把圖片與 PDF 頁面排到同一張畫布上

| :--- | :--- |

| **起草日期** | 2026-11-19 |

> 功能名稱定為「拼貼」（2026-11-19）；目錄卡片與動作頁標題的完整寫法依介面規格 4.10 另定，例如「拼貼」「拼貼成一頁」。

## 1. 要解決的問題

- 把幾張照片、截圖排成一張圖或一頁 A4（作業、報告附件、社群貼文）。
- 把 PDF 的幾頁縮小排在同一張紙上（講義一頁 4 張、6 張投影片），省紙或方便瀏覽。
- 身分證正反面、幾張發票排到同一頁 A4（與 F2-13 掃描件拼合相同的目的，F2-13 多了自動裁切與背景淨白）。

現有功能只能「上下接成長圖」（拼接長圖）或「每張一頁合成 PDF」（合成一份 PDF），都不能把多個項目排在同一個平面上，也不能指定畫布大小。

## 2. 範圍

**輸入**：圖片（PNG、JPG、WebP、HEIC 等目前支援的格式）與 PDF 頁面，可以混合。PDF 的每一頁都是一個可排的項目。

**畫布**：
- 紙張尺寸：A4、A3、Letter、Legal，直式或橫式。
- 自訂尺寸：寬 × 高，單位 px、mm 或 cm；常用的社群尺寸（1080 × 1080、1080 × 1350、1920 × 1080）列為預設選項。
- 背景顏色、邊界、項目之間的間距。

**排法**（由簡到繁，先做前兩種）：
1. **格狀**：指定「每張幾個」（1、2、4、6、9、16），項目依序填入；放不下時自動接到下一張。
2. **自動**：依項目數量與長寬比自動選欄列數，讓空白最少。
3. **自由排**：在畫布上拖曳、縮放、旋轉每個項目。第一版不做（2026-11-19），視需求再決定。

**每個項目**：放入方式預設「完整放入」（不裁切，留白），可改「填滿裁切」；旋轉 90°；順序調整（沿用合併的順序清單：拖曳、↑ ↓）。

**輸出**：
- PDF（多頁，每張畫布一頁）：**預設**，圖片與 PDF 混合時也是。
- 圖片（PNG、JPG；多張畫布時輸出多張圖片）：可在動作頁改。
- PDF 頁面在輸出 PDF 時盡量保留向量內容（以頁面為 XObject 放入），不先點陣化；輸出圖片時才點陣化。

**不在範圍內**：文字與標註、圖層、濾鏡、自動裁切與背景淨白（屬 F2-13）。

## 3. 介面方向（待畫布討論）

屬於「需要完整工作區的動作」（介面規格 4.6），動作頁直接放工作區：

- 左側：項目清單（縮圖、順序調整），與合併共用同一套元件。
- 右側：畫布預覽，即時反映紙張、方向、排法、間距；多張畫布時可翻頁。
- 上方：畫布大小、排法、每頁幾個；其餘選項（背景、邊界、間距、縮放方式）照 D2 攤平在卡片裡。
- 點兩下項目或畫布：沿用分割的放大預覽。

目錄出現的時機：選了 2 個以上的圖片、PDF，或圖片與 PDF 混合時出現；只有 1 個多頁 PDF 時也出現（把它的頁面排成多頁合一）。

## 4. 與其他功能的關係

| 功能 | 關係 |
| :--- | :--- |
| 拼接長圖 | 長圖是「1 欄、畫布高度隨內容」的特例。拼貼完成後可評估是否把長圖併入拼貼的一種排法，或保留為獨立的快速動作 |
| 合成一份 PDF | 每張一頁是「每頁 1 個」的特例，保留為獨立的快速動作 |
| 列印 | 列印的「每張紙印幾頁」（2026-11-19 已定案，見介面規格「列印預覽」）可直接呼叫拼貼的格狀排法，避免兩套排版邏輯 |
| F2-13 掃描件拼合 | 先自動裁切與淨白，再用拼貼的排法放到 A4 |
| 共用預覽元件 | 頁面縮圖與放大預覽沿用分割、合併、列印的同一套（見 [v4_cross_platform_master_plan.md](v4_cross_platform_master_plan.md)〈4.0 上線前清單〉12） |

## 5. 技術方向

- PDF 輸出：PdfSharp 已在 Core 中，可把來源頁面當成 XObject 縮放、旋轉後放到新頁面，保留向量；圖片直接繪入。
- 圖片輸出：沿用 PDF → 圖片的繪圖路徑（Windows 用內建 PDF 引擎；跨平台引擎見總計畫的 PDFium 計畫），再由 Skia 或 WIC 合成。
- 版面計算放在 Core（純計算、可單元測試），桌面端只負責預覽與互動，右鍵執行與 CLI 也能用同一套排法與設定。

## 6. 已決定（2026-11-19）

1. 名稱：「拼貼」。
2. 第一版只做「格狀」與「自動」，自由排留到之後。
3. 輸出預設 PDF，可改成圖片。
4. 項目放進格子預設「完整放入」（不裁切），可改「填滿裁切」。
5. 不提供右鍵直接執行：版面要看了才能決定，一律進工作區。

## 7. 待決

1. 間距、邊界的單位與預設值（mm 或 px，依畫布是紙張或像素尺寸切換）。
2. 自訂尺寸的上限（避免輸出過大的圖片）。
