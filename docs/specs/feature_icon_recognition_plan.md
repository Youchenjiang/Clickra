## 1. 現況

2026-11-16 起，桌面端改用正式功能圖示（`assets/features/*.svg`），由 `scripts/generate_desktop_feature_icons.py` 轉成 `src/Clickra.Desktop/Assets/FeatureIcons.axaml`，和右鍵選單是同一套。改用之後辨識度的問題更明顯，因為同一個畫面上會同時出現七、八個。

### 1.1 問題

| # | 問題 | 例子 |
| :--- | :--- | :--- |
| 1 | **同一種來源檔案的圖示全部同一個底色**，只能靠中間的小白色符號分辨 | 放入 PDF 時，目錄的 7 張卡片有 6 張是同一個灰藍色方塊 |
| 2 | **「底稿＋右下角徽章」的雙層造型用了 9 次**，縮小後徽章裡的符號看不清 | Word／Excel／PPT／MD／圖片 → PDF、PDF → 圖片、翻譯、重新命名、MD → Word |
| 3 | **外形相似**：只差在箭頭方向或細節 | 壓縮（箭頭向內）與分割（箭頭向外）；合併 PDF 與合併圖片；5 個「轉換圖片格式」只差徽章裡的字 |
| 4 | **深色背景對比不足**：PDF 主色 `#475569` 在深色選單（約 `#2B2B2B`）上只有 1.9:1，Markdown 紫 2.0:1、Word 藍 2.2:1，遠低於圖示建議的 3:1 | Windows 深色模式的右鍵選單、桌面端深色主題的歷史標籤 |
| 5 | **小尺寸細節太多**：文件橫線、底稿上的字母、徽章裡的箭頭在 16 px 時只剩 1 px 左右 | 右鍵選單（16）、歷史標籤（14） |
| 6 | **圖示裡寫字**：「轉換格式」卡片用的是 `img-to-png`，上面寫 PNG，轉成 JPG 時看起來不對；字母也無法翻譯 | 目錄的「轉換格式」 |

### 1.2 使用尺寸

| 位置 | 尺寸 | 背景 |
| :--- | :--- | :--- |
| 右鍵選單 | 16（125% 縮放時 20） | 淺色或深色系統選單 |
| 歷史與最近處理的功能標籤 | 14 | 檔案類型色 18% 淡底 |
| 動作頁標題 | 32 | 白色或深色卡片 |
| 動作目錄 | 52，放在 68 的淺色底上 | 淺色底（深色主題也是淺色底） |

最常看到的是 14–20 的小尺寸，因此**以 16 px 能不能分辨為準**，不是以 256 的原稿好不好看為準。

## 2. 目標

1. **每個動作只看外形就分得出來**：16 px、灰階之下，22 個圖示兩兩不相似。
2. **顏色只表示「處理哪種檔案」**，維持既有檔案類型色票；動作靠形狀分辨，不靠顏色。
3. **深色與淺色背景都看得清**：圖示主體和背景的對比至少 3:1。
4. **同一家族**：同樣的格線、圓角、線寬、留白，放在一起時大小一致。
5. **不在圖示裡寫字**。

不在這次範圍：Clickra 主標誌（`assets/primary`）、介面線條圖示（第 7 節，已統一）。

## 3. 設計原則

### 3.1 版面

- 原稿維持 256 × 256，四周各留 24 的安全區；主體大小一致（外框約 208）。
- 線寬至少 20（16 px 時約 1.25 px）；最小的實心元素至少 24。
- **一個主符號**表示動作，最多再加一個輔助元素；縮小後輔助元素可以不見，但主符號一定要看得出來。
- 圓角半徑統一（外框 36，內部元素 12）。

### 3.2 兩類圖示，兩種結構

| 類型 | 結構 | 適用 |
| :--- | :--- | :--- |
| **處理類**（同一種檔案做某件事） | 檔案類型色的圓角方塊，中間一個白色主符號，不放文件橫線 | 壓縮、分割、合併、翻譯、解密、列印、重新命名、圖片壓縮、圖片合併、拼接、轉成圖片 |
| **轉換類**（A 格式 → B 格式） | 左上角來源色、右下角目標色，對角切成兩半，中間一個白色箭頭；不再疊卡片、不放字母 | Word／Excel／PPT／MD／圖片 → PDF、MD → Word、PDF → 圖片 |

轉換類一律用同一個結構，只靠兩個顏色分辨：使用者本來就是看「從哪種檔案變成哪種檔案」，對角兩色比字母更快讀到，縮小也不會糊掉。

### 3.3 深色背景

- 每個方塊加一圈 8 寬、較亮的同色外框（亮度提高約 40%），或在深色模式改用較亮的色票；兩種做法在畫布並排比較後選一種。
- 目標：主體對 `#2B2B2B` 至少 3:1。

## 4. 每個功能的新主符號（草案，第一步在畫布上比較）

| 功能 | 現在 | 改成 | 和誰容易混淆、如何分開 |
| :--- | :--- | :--- | :--- |
| 壓縮 PDF | 文件＋兩側向內箭頭 | 上下兩個箭頭夾住一條橫線（擠壓） | 分割：分割改用剪開的造型，不再是箭頭 |
| 分割 PDF | 兩張卡片＋向外箭頭＋虛線 | 一張紙被斜線剪開成兩半，中間留縫 | 壓縮（見上） |
| 合併 PDF | 兩張疊卡＋圓形加號 | 兩條線匯成一條（Y 字匯流） | 合併圖片同符號、不同底色 |
| PDF → 圖片 | PDF 底稿＋圖片徽章 | 轉換類：灰藍 → 青綠，對角箭頭 | 其他轉換類只差顏色 |
| 翻譯 PDF | A 字底稿＋紅色交換徽章 | 兩個對話框交疊（一個寫「文」形的抽象筆畫，另一個寫「A」形的抽象筆畫，不用真字） | — |
| 解密 PDF | 打開的鎖 | 維持，鎖身加大、鎖勾加粗 | 已經清楚 |
| 列印 PDF | 印表機 | 維持，拿掉出紙口細節 | 已經清楚 |
| Word／Excel／PPT／MD → PDF | 字母底稿＋PDF 徽章 | 轉換類：來源色 → 灰藍 | 只差來源色，和右鍵選單出現在該檔案上時的情境一致 |
| MD → Word | 字母底稿＋Word 徽章 | 轉換類：紫 → 藍 | — |
| 圖片 → PDF | 風景底稿＋PDF 徽章 | 轉換類：青綠 → 灰藍 | — |
| 圖片壓縮 | 相框＋向內箭頭 | 同「壓縮 PDF」的主符號、青綠底 | 同動作同符號 |
| 合併圖片 | 兩張疊卡＋圓形加號 | 同「合併 PDF」的主符號、青綠底 | 同動作同符號 |
| 拼接圖片 | 上下兩條＋連結 | 上下兩個方塊接成一條長條（中間一條接縫線） | 合併：合併是匯流，拼接是上下相接 |
| 轉換圖片格式（png／jpg／webp／heic／gif） | 照片＋寫字的膠囊 | 一個圖示：照片符號＋循環箭頭；選單第二層的各格式項目只寫文字，不放圖示 | 不再寫字 |
| 批次重新命名 | 藍色文件＋青綠徽章＋筆 | 一個文字游標「I」加底線（改名字） | — |

原則：**同一個動作在不同檔案類型用同一個主符號、換底色**（壓縮、合併），讓使用者學一次就會。

## 5. 滑過時的小動畫（第三步，可選）

- 只在動作目錄的卡片上，滑過或用鍵盤選到時播一次，約 0.4 秒；系統開啟「減少動態效果」時不播（沿用 `Motion.Enabled`）。
- 例子：分割＝紙張沿縫左右分開一點再回來；壓縮＝上下箭頭往中間推一下；合併＝兩條線往中間收；翻譯＝兩個對話框交換位置。
- 做法：目錄卡片改用 XAML 繪製的同一份圖形（不是 `DrawingImage`），把要動的部分拆成獨立的元素，只動位移、縮放與透明度（第 7 節動畫限制）。右鍵選單與小尺寸不播放。
- 成本：每個圖示多一份可動的版本。先做 3 個（分割、壓縮、合併）確認效果與維護成本，再決定是否全做。

## 6. 步驟

| 步驟 | 內容 | 產出 |
| :--- | :--- | :--- |
| 1. 比較 | 在畫布上把現在與新草案並排：16、20、32、52 四種尺寸 × 淺色、深色背景，另加一張灰階版 | 畫布「比較：功能圖示辨識度」 |
| 2. 定案 | 選出結構（3.2）、深色背景做法（3.3）與每個主符號；記入 `v4_desktop_ui_layout.md` 決策紀錄，待決事項 8 改為已決 | 規格更新 |
| 3. 重畫 | 依定案重畫 `assets/features/*.svg`；「轉換圖片格式」改為一個圖示 | 新的 SVG |
| 4. 產生 | 執行 `scripts/tools/IconGen`（右鍵選單 PNG／ICO）與 `scripts/generate_desktop_feature_icons.py`（桌面端） | 更新後的圖示資源 |
| 5. 檢查 | 自動產生一張檢查圖：22 個圖示 × 4 種尺寸 × 2 種背景，附對比數值；人工看過 | `tmp/icon-sheet.png` |
| 6. 試用 | 找 3–5 個沒看過的人，每次只看一個 16 px 圖示 2 秒，說出是什麼功能；答對率低於 80% 的圖示回到步驟 3 | 試用紀錄 |
| 7. 動畫（可選） | 依第 5 節先做 3 個 | — |

分支：`design/feature-icons`。提交依序為 `docs(specs)`（定案）、`feat(assets)`（SVG）、`chore(desktop)`（重新產生資源）、`test(core)`（下方的檢查）。

## 7. 驗收

- 22 個圖示在 16 px 灰階下兩兩可分辨（步驟 6 的答對率每個至少 80%）。
- 每個圖示主體對淺色（`#FFFFFF`）與深色（`#2B2B2B`）背景的對比都至少 3:1。
- 沒有任何圖示含文字。
- 右鍵選單（3.x、4.0）與桌面端顯示的是同一份圖示；`FeatureIcons.axaml` 與 SVG 同步（加一條測試：重新執行產生腳本後檔案不變）。
- 動作目錄、動作頁、歷史標籤、右鍵選單截圖各一張，淺色與深色主題都看過。
